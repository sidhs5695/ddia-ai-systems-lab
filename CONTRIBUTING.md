# Contributing

This is a two-person DDIA + AI study lab. Keep contributions small enough to review and discuss in one sitting.

## Branch naming
Use `ch01/<name>-<topic>`, `ch02/<name>-<topic>`, `ai/<name>-<topic>`, or `docs/<name>-<topic>`.

## Workflow
1. Pick one open study issue.
2. Branch from `main`.
3. Make one focused learning change.
4. Open a PR and link the issue.
5. The other study partner reviews the reasoning as well as the code.
6. Discuss the trade-off.
7. Merge when both people can explain what the experiment demonstrated.

## Every experiment should answer
- What behavior are we trying to observe?
- How do we reproduce it?
- What happened?
- Why did it happen?
- What mitigation did we try?
- What trade-off did it introduce?
- Which DDIA concept does it connect to?

## Review checklist
- Can I reproduce it?
- Is the observation measured rather than assumed?
- Does the README explain why it matters?
- Did a framework hide the behavior we wanted to learn?
- Can both contributors explain the trade-off?

Normal study work should go through PRs rather than direct pushes to `main`.
