# Architecture Decision Records

Use this directory for decisions where the trade-off matters more than the final choice.

Suggested format:

```md
# ADR-0001: Title

## Context
What problem or experiment forced this decision?

## Options
What realistic alternatives did we consider?

## Decision
What did we choose for this lab?

## Consequences
What becomes easier? What becomes harder?

## DDIA connection
Which principle or chapter does this demonstrate?
```

Do not create an ADR for trivial formatting or framework choices.
