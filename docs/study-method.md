# Study Method

## Default session: 25–30 minutes
Each session has exactly three parts:
1. **Reading (5–10 min)** — one small DDIA section.
2. **Experiment (15–20 min)** — one observable system behavior.
3. **Takeaway (2–5 min)** — one sentence or question.

No streak pressure. If progress stalls, simplify the unfinished task instead of advancing.

## One unfinished project at a time
Do not start the next chapter implementation before the current chapter completion criteria are met.

## Pair-study rhythm
- Session A: one person implements or measures.
- Session B: the other person reviews, challenges assumptions, or reproduces.
- Session C: swap roles or close the mini-experiment.

A chapter is complete when both contributors can explain the failure mode, reproduce it, explain the mitigation, and describe at least one trade-off.
