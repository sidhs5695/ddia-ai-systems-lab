# DDIA + AI Systems Roadmap

1. **Reliable, Scalable, Maintainable** → Production API Under Load
2. **Data Models & Query Languages** → Multi-tenant Document & Permission Service
3. **Storage & Retrieval** → Mini Storage Engine
4. **Encoding & Evolution** → Versioned Event/API Platform
5. **Replication** → Replicated Profile Service
6. **Partitioning** → Sharded Key-Value Store
7. **Transactions** → Wallet / API Quota Service
8. **Distributed-System Failures** → Resilient Microservice Chaos Lab
9. **Consistency & Consensus** → Distributed Job Coordinator
10. **Batch Processing** → AI Document Batch Pipeline
11. **Stream Processing** → Kafka Real-time Ingestion
12. **Future / Derived Data** → RAG Knowledge Platform

## AI track
Layer AI engineering on top of the systems foundation:
LLM fundamentals → structured outputs → embeddings → vector search → RAG → tool calling → evaluation → latency/cost/versioning.

The goal is practical AI engineering for software engineers, not model research.
